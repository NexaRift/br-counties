# Condado de Curitiba (PR)

O **Condado de Curitiba** corresponde à **Região Geográfica Imediata de Curitiba**, reunindo os municípios que a compõem conforme a regionalização adotada. O condado constitui uma unidade territorial utilizada para a consolidação de indicadores demográficos, sociais, econômicos e geográficos de seus municípios integrantes.
