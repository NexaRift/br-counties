# Condado de Pitanga (PR)

O **Condado de Pitanga** corresponde à **Região Geográfica Imediata de Pitanga**, reunindo os municípios que a compõem conforme a regionalização adotada. O condado constitui uma unidade territorial utilizada para a consolidação de indicadores demográficos, sociais, econômicos e geográficos de seus municípios integrantes.
